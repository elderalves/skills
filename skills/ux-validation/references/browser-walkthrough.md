# Browser walkthrough

1. In T3 Code, start with `preview_status`. Reuse the target tab when it is available and you can act in it. Otherwise open the target in a new preview tab and use its ID for each call. Prefer snapshot locators. If T3 preview is unavailable, unsupported, or fails twice at a step, use browser automation in an isolated session. Put the capture tool and any fallback reason in `coverage.capture`. For `agent-browser`, load `agent-browser skills get core` and its recording reference before using those commands.
2. Open the requested section and check access. Use an existing authorized session or let the user sign in through the browser if an attended handoff is available. If the sign-in wall remains, capture what is visible and record the gated portion as a coverage gap. Use test data for interactions with side effects. Stop before external or irreversible actions unless the request authorizes them.
3. Attempt the task as the intended user from the stated starting point. Record what you did and what the interface actually showed for each meaningful step. Include errors, recovery, and the final outcome. When a narrow viewport matters, replay the relevant steps at that width and record it. Treat a browser width check as evidence for that viewport.
4. Capture the state after each meaningful step when it helps explain the outcome or a finding. In T3, use `preview_snapshot` with `save: true` and copy the returned image to the run's `assets/`. Give it meaningful alt text. After inspecting the image, record a [screenshot marker](report-format.md#screenshot-markers) for the relevant UI. Record the visible target bounds when they can be measured in the capture. Use a point for evidence that identifies a location alone.
5. For a transient state, start recording before the action and stop as soon as the behavior is visible. In T3 use `preview_recording_start` and `preview_recording_stop` on the same tab. Copy the returned MP4 or WebM into `assets/` and verify it contains the relevant interaction. Use a short caption that tells the reader what to watch for. If recording or playback fails, use the still evidence available and record the missing clip as a gap.
6. Inspect captures for private information before reviewers or readers see them. Crop or redact the relevant media in the run if needed, then check marker points and bounds against the resulting image. Omit media you cannot safely include and explain the coverage gap. Close your own preview tab when done unless the user is using it or asked to keep it.
